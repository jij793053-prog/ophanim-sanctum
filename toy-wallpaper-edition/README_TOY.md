# Ophanim Sanctum — 纯观赏玩具与桌面动态壁纸版 (Toy & Wallpaper Edition)

这是 **Ophanim Sanctum（座天使圣轮）** 的极简独立版本，**无需安装 Python、无需安装任何第三方库、更不需要连接任何 AI Agent**。

## 目录内仅 2 个核心文件（各司其职）

1. **`ophanim_toy_sanctum.html`（单文件 3D 网页模板 / 把玩本体）**
   - **只当网页玩具或前端模板用时，只要这 1 个 HTML 文件就够了**（你可以单独把这一个 `.html` 拷到任何地方双击离线打开，所有七重圣轮、52 颗跟鼠圣瞳、阶梯金字塔动效与参数调节全部完整可用）。
2. **`Ophanim_Wallpaper_Toy.bat`（单文件零依赖 Windows 动态壁纸器）**
   - **为什么设为桌面壁纸多这 1 个文件？** 因为浏览器自身的安全沙盒禁止纯 `.html` 网页直接修改 Windows 桌面底层窗口（`Progman / WorkerW`）。这个 `.bat` 直接调用 Windows 10/11 系统自带的原生接口将圣轮挂载到桌面图标下方并隐藏任务栏图标，**跟 AI 桥接没有任何关系**，也不需要安装 Python。
   - **使用方法**：
     - 双击 `Ophanim_Wallpaper_Toy.bat` 打开圣轮界面，调好喜欢的视角与参数后点击左下 **`✦ 设为壁纸`**，即刻嵌入桌面作为可交互动态壁纸（随时可点 **`✕ 取消壁纸`** 恢复原壁纸）。
     - 运行过一次 `Ophanim_Wallpaper_Toy.bat` 后，系统会自动记住本地唤醒通道——之后哪怕你是**直接双击 `ophanim_toy_sanctum.html`** 打开网页，在网页里直接点 **`✦ 设为壁纸`** 也能一键自动设为桌面壁纸！

## 核心 3D 交互手势（窗口模式 & 桌面壁纸模式通用）
- **眼睛实时跟鼠**：52 颗黑底圣瞳随光标实时凝视。
- **左键拖拽空白处**：自由旋转三维星系视角（壁纸模式下不影响桌面图标点击与框选）。
- **点击发光白球一键归位**：在动态壁纸（或金字塔预览）下，直接在桌面上左键点一下顶端纯白圣球，即可丝滑收拢恢复三维轨道姿态。
- **按住鼠标中键拖拽任意一环**：单独拨动任意一圈圣轮或最外圈刻度基座线的空间倾角。
- **滚轮缩放视角**：窗口内直接滚轮缩放；桌面壁纸模式下**按住鼠标中键 + 滚轮**缩放（防止桌面误触）。
