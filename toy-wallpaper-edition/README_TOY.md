# Ophanim Sanctum — 纯观赏玩具与互动动态壁纸版 (Toy & Interactive Wallpaper Edition)

这是 **Ophanim Sanctum（座天使圣轮）** 的独立纯观赏 + Windows 桌面互动动态壁纸版本，**无需安装任何 AI 编程工具或 Agent** 即可直接把玩或设为桌面壁纸。

## 启动与生成桌面 LOGO 图标

1. **直接网页把玩（免 Python）**：双击 `ophanim_toy_sanctum.html` 即可在浏览器离线把玩。
2. **独立窗口 + Windows 动态壁纸（推荐）**：
   - 运行一次 `pip install aiohttp`
   - 双击 `Start_Toy_Wallpaper_App.bat` 启动应用（或双击 `Create_Toy_Desktop_Shortcut.bat` 在桌面生成带**圣轮玫瑰星盘专属 LOGO** 的快捷方式）。
   - 在左侧司仪台底部点击 **`✦ 设为壁纸`** 即可将当前圣轮嵌入桌面图标层下方。

## 核心 3D 交互手势（窗口模式 & 桌面壁纸模式通用）
- **眼睛实时跟鼠**：52 颗黑底圣瞳随光标实时凝视。
- **左键拖拽空白处**：旋转三维视角。
- **点击发光白球一键归位**：在动态壁纸（或预览模式）下当圣轮展开为七层阶梯金字塔并点亮顶端纯白圣球时，**直接在桌面上左键点一下那颗发光白球**，即可完成查阅并丝滑收拢变回三维轨道姿态！
- **按住鼠标中键拖拽任意一环**：指向任意一圈圣轮并按住中键拖动，单独拨动该环三维倾角。
- **滚轮缩放视角**：在**普通窗口界面内直接滑动滚轮**即可调节大小；在**桌面动态壁纸模式下按住鼠标中键 + 滑动滚轮**调节远近（防止在桌面误触滚轮）。
- **分类一键重置（`↺ 重置`）**：每个参数分类右上角均可一键恢复该组初始默认值。
